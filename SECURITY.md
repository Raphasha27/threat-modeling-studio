# Security Policy

## Intended Use
- Education
- Research
- Defensive Security
- Security Awareness
- Security Training
- Penetration Testing (authorized environments only)

## Prohibited Use
- Unauthorized Access
- Credential Theft
- Malware Distribution
- Denial of Service Attacks
- Surveillance of unsuspecting users
- Any illegal activity

## Reporting Vulnerabilities
Report vulnerabilities responsibly to the repository owner. Do not disclose unpatched vulnerabilities publicly.

## Compliance
This project complies with responsible disclosure standards. Use only in isolated, authorized environments.
